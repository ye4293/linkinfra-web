# 首页重设计与审查记录

本次修改 `/` 首页，参考 OpenRouter 收敛为黑白灰与紫色强调，保留中英文、移动导航、公开模型目录、价格比较和接入示例。后台页面继续使用现有实现。

## 数据与交互

- 模型与分组价格来自 `/api/model-plaza`，支持分页读取与模型 ID 去重。
- 按模型系列选择展示项，使用数字版本排序；首屏不再写死具体版本或声称某个版本是最新发布。
- 搜索同时支持模型 ID、展示名称和页面使用的厂商别名。
- 输入、输出按 USD / 百万 Tokens 展示；按次计费模型单独展示单位。
- 近 24 小时监控数据来自 `/api/model-plaza/metrics/all`，无观测数据时隐藏该行。
- 支持厂商、计费方式、价格分组与排序；输入 `/` 或点击顶部搜索可定位搜索框。
- Python、Node.js、cURL 示例支持切换与复制，API Key 通过环境变量配置。

## 审查修复

1. 展示名称与模型 ID 的标点不同，导致搜索不到对应模型；已统一搜索规范化。
2. 版本清理规则会误删 DeepSeek 的 `v3` 等版本；已限定部署后缀清理的范围。
3. API 集合为空或字段异常时可能导致渲染错误；已规范化空集合，并在数据入口验证必需字段，错误进入重试状态。
4. 价格分组更新后选择可能失效；已回退到当前目录的有效分组。
5. 浅灰文字对比度不足、移动端辅助字号偏小；已调整对比度与字号。
6. 手机端代码块无法用键盘聚焦滚动；已补充焦点与可访问名称。

## 验证

- `npm run test:landing`：7 项回归测试，覆盖名称、搜索、版本排序、价格、分页、空集合与异常数据。
- 浏览器验证：厂商/搜索/计费筛选、排序、价格组、代码切换与复制、FAQ、语言持久化、移动导航、失败重试。
- 响应式检查：320、390、768、1024、1440px。
- axe 自动检查：中英文各自的桌面与手机布局，WCAG 2 A/AA、2.1 AA、2.2 AA 标签范围内无违规项。自动检查不等同于完整人工无障碍认证。
- `npm run build`：生产构建与类型检查。
