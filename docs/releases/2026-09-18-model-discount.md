# 模型折扣

- 模型价格配置的可视化表格新增“模型折扣”列，默认 1.0；修改多行后点击“统一保存”一次提交，也可点击行内按钮或按 Enter 单独保存。
- 未保存的折扣在翻页、搜索和刷新列表时保留，统一保存包含其他分页的修改。保存失败保留草稿，非法折扣阻止统一提交。
- 统一保存增量验证：生产构建通过；使用 React Test Renderer 和模拟接口验证跨页草稿、搜索/刷新、一批提交、失败重试、非法值、保存期间禁用、单行保存隔离及恢复原值。
- 折扣范围为大于 0 且不超过 1，0.8 表示八折，1 恢复原价。原有价格字段保留基础价格。
- 模型广场卡片、表格和详情展示删除线原价、折后价和 OFF 比例，覆盖 Token、按次和按分钟计费。
- API 的模型字段新增 `model_discount`；服务器返回的分组最终价格已包含模型折扣，客户端不会重复相乘。
- 已通过 TypeScript、生产构建、目录回归以及本地浏览器桌面/手机模拟数据检查。需与后端模型折扣版本一同发布。
