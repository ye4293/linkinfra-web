# 音频按时长计费前端补齐

实际前端为 linkinfra-web，配套后端为 linkinfra。后端原有 f210bec 实现时长计费，本轮发布模型级保存接口并补齐实际前端。

## 变更

- 设置 → 模型定价 → 按时长计费：支持单个或每行一个模型的批量设置，0 表示免费；支持移除时长配置、搜索和编辑，并区分后端不支持、加载失败及保存失败。
- 保存走单模型或批量 pricing 接口，由后端合并所选模型，避免前端全量覆盖其他配置；较早发出的读取结果不会覆盖新选择。
- 已配置列表和未设置列表提供时长计费入口；美元/分钟与每百万 Token 明确区分。
- 首页目录接受 `duration` 模型并验证分钟价格；广场卡片、表格、详情和价格分组显示分钟单价，提供按时长筛选。
- 桌面与手机日志展示上游秒数、分钟单价、组合倍率及实际结算 quota。显式 0 秒保留，缺失时长不伪装为 0 秒或 Token 用量。

## 验证与发布

- 前端生产构建通过；目录及音频日志解析回归通过，增加价格与日志组件渲染检查。
- 后端配置、并发保存、余额调整、转录与流式计费回归，以及完整 build/vet 在隔离检出目录中通过。
- 自动审批拦截了带模拟认证配置的本地服务启动，未完成本轮管理页面的浏览器点击验收；不能将组件与接口测试称为完整端到端验证。
- 先部署后端模型级价格更新接口，再部署前端。推送 GitHub 不等于完成部署或真实上游验收。
- 移除普通转录模型的分钟价格后恢复已有计费配置；必须按时长计费的 `gpt-transcribe` 及受保护映射需要重新配置价格才能使用。
