# 意见报告第一批修改（1—8）

本批将公共导航统一为首页、模型广场、文档和 Console，并修复报告涉及页面的语言切换、模型配置传递和首屏显示问题。未部署。

## 变更

1. 补齐模型广场、密钥列表、创建密钥、客户端配置、新手引导和共享后台导航的中文文案；修复中文语言包中的相关英文内容。
2. 新手指引支持中英文，API 文档延续已有双语内容。语言选择使用共享域 Cookie 和本地存储，登录链接同时携带语言，服务端按 Cookie 输出初始语言。
3. 首页、模型广场、文档、Console、新手指引使用共享导航链接；移动端保留返回首页和进入模型广场的入口。
4. 首页右上角明确展示 Console，模型广场提供 Console 链接。
5. 模型详情的获取密钥链接携带模型 ID；未登录重定向、创建密钥、编辑密钥和提交后返回列表保留该参数。客户端配置自动填入模型，并选择相应应用；未知模型保留 ID 并进入手动配置。
6. 客户端候选模型按应用筛选，手动输入及 Claude 可选映射也会校验。切换应用时清除不匹配模型和可选映射。显式协议元数据优先于名称规则。
7. “出生日期”确认是 `expired_time` 到期字段，已改为“到期时间 / Expiration date”，日期组件支持中文；不选日期明确提交 `-1`（永不过期）。
8. 压缩常见笔记本屏幕下首页首屏留白，保留完整卡片内容；手机端自然滚动，不强制压缩所有内容进一屏。

## 协议数据限制

当前后端 `/api/user/models` 仅返回模型名称，不返回每个渠道的实际协议能力。因此现阶段筛选使用保守的模型系列规则，并在配置页面说明尚未验证渠道兼容性。自定义别名可使用手动配置；前端已支持 `{ id, protocols }` 形式的明确协议数据，未来后端提供后可优先使用，无需按品牌猜测。

本批未包含第二批的密钥页布局重排、弹窗固定尺寸、模型广场分页/固定筛选，以及首页动效等改动。上述后续工作与最新验收范围见 [第二批及逐项落实报告](2026-09-16-report-second-batch.md)。
