# 网站公告栏

- 展示位置：首页导航下方、控制台首页顶部。
- 管理入口：系统设置 → 网站公告，支持纯文本多行内容、实时预览和独立保存。可在同一正文填写中文与英文。
- 清空内容后保存即可隐藏；长公告默认显示两行，可展开/收起。已打开页面在重新聚焦或最多一分钟内重新读取公告。
- 复用现有后端 Notice 配置及 `/api/notice`；保存仅更新 Notice，沿用 `/api/option` 的管理员权限，无需更新后端或迁移数据库。
- 公告按纯文本显示，不执行 HTML；加载失败不影响主页面。没有发布示例内容或修改线上公告。

验证：生产构建通过；3 项测试覆盖保存范围及失败行为、空内容与异常响应、HTML 按纯文本显示。Edge 检查 1366、390、320px 布局、展开/收起、清空隐藏、更新重读和失败恢复，无横向溢出或运行时异常。后台保存请求以模拟数据验证，未通过真实账户发布公告。
