## 剩余事项及验收标准

1. **头像交互**：若继续采用原文方案，需在鼠标悬停可达、触屏点击和键盘操作之间给出一致入口；现有 Console 链接可直接使用。
2. **视频素材**：补齐参考提示词或确定画面与文案，生成素材后检查首屏加载成本、移动端裁切、暂停与减少动态效果。当前交付是网页动效，不是视频文件。
3. **营销与订阅**：明确“订阅”的业务事件、统计周期、去重规则和运营优先级；由后端在分页前排序，并标注推广内容。不能把请求量当作订阅量。
4. **真实联调与发布**：发布后使用测试账户验收跨域登录回跳、真实渠道协议、实际客户端导入，以及真实计费和账户权限。
