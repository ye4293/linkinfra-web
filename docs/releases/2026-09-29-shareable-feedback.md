## 验证

- `node --test scripts/test-review-navigation.cjs scripts/test-client-setup.cjs scripts/test-landing.cjs scripts/test-date-time-range.cjs`：25 项通过，覆盖登录链接中的模型/语言传递、应用配置、目录搜索和价格，以及日期边界、闰年、周日起算、时间戳与无效范围。
- TypeScript 检查通过；新日期组件、接入弹窗、密钥表单及用量筛选的定向 lint 无警告。
- `npm run build` 通过，包含生产编译、类型检查及 95 个页面生成；仅有既存的 `components/icons.tsx` 未使用导入和 Browserslist 数据过期提示。
- Chromium 使用本地模拟会话和接口，验证复用/创建密钥后进入配置、创建失败保留表单、复制、分页及改变条数重置页码；模型广场筛选/翻页/详情返回/失败重试；日期选择、时间下拉、应用/取消、全部时间刷新、非法范围、Escape 与焦点归还。
- 密钥与 Usage 页面在 1440、1024、390、320px 下无页面横向溢出、无嵌套纵向滚动，鼠标滚轮可滚动主页面；模型广场另覆盖 1920、768px 和中英文卡片/表格视图。最终浏览器检查无运行时异常。
- 截图在 `design-mockups/shareable-review/`，均为模拟数据；不代表真实账户、密钥或业务量。

本地验收没有调用真实模型或写入真实账户。跨域登录、真实客户端导入和线上发布仍需部署环境验收。接入弹窗的现有密钥列表沿用当前页结果；可关闭弹窗搜索或翻页后重新打开。
