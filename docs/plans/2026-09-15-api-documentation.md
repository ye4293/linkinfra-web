# API 文档页面

## 背景与目标

为 LinkInfra 新增无需登录的 API 文档，参考 New API 文档的分组侧栏、接口说明和代码示例布局。内容以关联 Go 项目的实际路由、鉴权中间件和请求结构为依据。

## 方案设计

- 在 `app/docs/[[...slug]]/page.tsx` 注册文档路由，支持独立链接、页面元数据和无效路径 404。
- 在 `lib/api-docs/` 维护中英文接口目录、字段说明和代码示例生成器。
- 在 `components/docs/` 实现响应式三栏页面、文档搜索、嵌套参数展开、代码复制和语言切换。
- 默认展示对话接口；提供快速开始、身份验证、错误处理，以及 Responses、Claude、Gemini、图像、音频、向量和模型查询文档。
- 将公共导航的默认文档地址调整为 `/docs`，保留已配置的外部文档地址。
- 根据最终展示要求，文档品牌使用 `Linkinfra API`，Base URL 使用 `https://api.linkinfra.ai`。示例中的模型 ID 需以用户账户实际可用模型为准。

## 影响范围

仅修改 `linkinfra-web`，沿用现有主题、语言、登录和公共配置。无需修改 Go 后端或数据库，不在文档页面自动发起计费调用。

## 验证方式

- TypeScript、ESLint、生产构建和现有相关回归检查。
- 检查文档路径与 Go 路由一致，验证多语言示例、JSON 和文件上传请求生成。
- 使用浏览器检查桌面、移动端、深浅色、搜索、目录导航、锚点和复制行为。
