# 文档入口与 API 地址恢复

文档已内置，移除后台 DocsAddress 输入与保存。线上状态接口当前返回正确 ServerAddress，但旧配置 Hook 会永久缓存一次失败得到的空值，使客户端配置持续缺少 endpoint。

公开配置改为可订阅缓存，只缓存成功结果，失败可重试；组件重新挂载或网络恢复时重新读取，成功后同步所有使用者。客户端配置和密钥页区分读取失败与未配置，提供重试。文档固定为 `/docs`，系统设置保存后刷新公开配置，状态代理禁止缓存。

验证首次失败后恢复、并发请求去重、订阅更新、强制刷新、文档站内导航与协议地址生成；执行类型检查和生产构建。不修改后端业务数据。
